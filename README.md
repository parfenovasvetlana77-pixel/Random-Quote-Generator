# Random Quote Generator

**Автор:** Редькин Никита

## Описание проекта

Random Quote Generator — это desktop-приложение с графическим интерфейсом на Python, которое генерирует случайные цитаты, сохраняет историю, позволяет фильтровать по автору и теме, а также добавлять собственные цитаты.

## Функциональные возможности

- Генерация случайной цитаты из предопределённого списка (9 цитат)
- Сохранение истории всех цитат с временной меткой
- Добавление новых цитат пользователем (с проверкой на пустые поля)
- Фильтрация истории по автору и по теме
- Сохранение истории в JSON-файл и загрузка при запуске
- Удобный графический интерфейс на tkinter

## Технологии

- Python 3.6+
- tkinter — GUI
- random, json, os, datetime
